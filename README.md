# AI Workplace Productivity Assistant

**Work smarter. Communicate clearly. Research efficiently.**

A modern, responsive web application designed to simplify everyday professional tasks through AI-assisted email drafting, research support, and workplace chat.

**Author:** Kashin Chetty

**Live Demo:** [AI Workplace Productivity Assistant](https://ai-productivity-assistant-portal.lovable.app/)

**GitHub:** [WebDev-ctrl1](https://github.com/WebDev-ctrl1)

## Project Overview

The AI Workplace Productivity Assistant brings three productivity tools into one modern workspace. It is designed to help professionals draft professional emails, organise research, and get assistance with everyday workplace tasks through an intuitive dashboard.

This project was developed for **educational, demonstration, and portfolio purposes**.

## Features

### Smart Email Generator
- Generate professional emails using user-provided context and instructions.
- Choose between Formal, Friendly, and Persuasive tones.
- Create follow-ups, meeting requests, customer support emails, and job applications.
- Edit, copy, regenerate, and clear generated content.

### AI Research Assistant
- Enter a topic or question, or paste article content for analysis.
- Summarise, explain, compare, and generate recommendations.
- Organise research into key findings and important considerations.
- Edit and copy generated results.

### AI Workplace Chat
- Interactive conversational interface for workplace questions.
- Suggested prompts to help users get started.
- Support for conversation context when available through the AI integration.
- Copy responses and start new conversations.

### Dashboard and User Experience
- Modern dashboard with sidebar navigation.
- Responsive design for desktop, tablet, and mobile.
- Clean interface and reusable components.
- Form validation, loading states, and error handling.
- Responsible AI disclaimer.

## Setup Instructions

### Prerequisites

- Node.js and npm
- Git
- An AI provider account if live AI functionality is required

### 1. Clone the repository

```bash
git clone <YOUR_REPOSITORY_URL>
cd <YOUR_PROJECT_DIRECTORY>
```

Replace the placeholders with your actual repository URL and project directory.

### 2. Install dependencies

```bash
npm install
```

### 3. Configure AI integration

Follow your selected AI provider's setup instructions if an integration is required.

**Security:** Never expose private API keys or secret credentials in frontend code. Use a secure, provider-supported integration or a server-side proxy when necessary.

### 4. Run the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### 5. Build for production

```bash
npm run build
```

## Responsible AI and Privacy

- Review AI-generated content before using it professionally.
- Verify research findings against reliable sources.
- Avoid entering confidential or sensitive information unless the AI provider's data-handling practices have been reviewed.
- Distinguish genuine AI responses from simulated demo content.
- Do not claim external websites have been researched unless their content has actually been accessed and analysed.
